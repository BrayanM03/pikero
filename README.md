## 🚀 Acerca de Pikero

**Pikero** es un sistema ERP diseñado para optimizar y centralizar la gestión de procesos empresariales. Cuenta con una arquitectura modular y escalable para adaptarse a las necesidades operativas de diversos negocios, facilitando el control de áreas clave desde una sola plataforma.

---

## ✨ Características Principales

* **Gestión Centralizada:** Control integral de módulos empresariales clave.
* **Arquitectura Modular:** Estructura limpia dividida en controladores, modelos y servicios para un fácil mantenimiento.
* **Interfaz Adaptativa:** Diseñado para ofrecer una experiencia de usuario fluida y eficiente.
* **Seguridad y Control:** Gestión de accesos y protección de rutas mediante `.htaccess` y configuraciones avanzadas.
* **Automatización de Assets:** Integración con Webpack para la gestión de recursos frontend.

---

## 🛠️ Tecnologías Utilizadas

Este proyecto está construido con las siguientes tecnologías y herramientas:

* **Backend:** PHP (con Composer para la gestión de dependencias)
* **Frontend:** JavaScript / Node.js, Webpack, PostCSS
* **Base de Datos:** MySQL / Relacional (gestionada desde el directorio `database`)
* **Servidor / Enrutamiento:** Apache (`.htaccess`)

---

## 📋 Requisitos Previos

Asegúrate de contar con lo siguiente instalado en tu entorno de desarrollo antes de comenzar:

* [PHP](https://www.php.net/) (versión 8.0 o superior recomendada)
* [Composer](https://getcomposer.org/)
* [Node.js](https://nodejs.org/) y npm
* Un servidor web local (como Apache o Nginx) o el servidor interno de PHP.
* Un sistema de base de datos compatible (MySQL / MariaDB).
